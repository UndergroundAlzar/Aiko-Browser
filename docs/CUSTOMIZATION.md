## 一、巴别塔（Babel）沉浸式双语翻译

从底部工具栏打开 **「⋯ → 巴别塔翻译」**（或在地址栏直接输入 `/babel`，亦可在定制中心开启底栏快捷图标）：

### 引擎选择与无感降级
- **Google 翻译（默认 · 免 Key）**：零配置直连，自动检测源语言并智能合并段落。
- **微软必应翻译（国内直连 · 免 Key）**：Edge 浏览器同款神经机翻，国内网络环境下免翻墙直连且质量极佳。
- **有道翻译（国内备用）**：作为国内网络的补充备选源。
- **Google 不通自动切国内**：默认开启。当使用 Google 遇到超时或无法连接时，自动无感切至微软必应继续翻译，不打断阅读。

### 自定义 AI API（极客上限）
选择 **「自定义 AI API」** 后可管理多套模型预设，支持 **OpenAI 兼容格式**（New API / OneAPI / DeepSeek / OpenRouter / SiliconFlow / Ollama 等）与 **Gemini 原生格式**：
- **自动拉取模型列表**：填好 Base URL 与 API Key 后点「获取模型」，自动拉取可用模型并支持搜索挑选，也随时支持手动输入任意自定义模型标识。
- **全参数可调**：**最大并发数（1–16）**、**单次最大 Token（128–32768）**、**温度（0.0–1.5）**、单批最大字符数（400–12000）、单批最大条数（1–30）、超时秒数（5–120s）、自定义请求头，以及 5 套内置风格 Prompt（标准精准 / 技术文档 / 自然中文润色 / ACG 角色扮演 / 学术论文）+ 自定义系统提示词。

### 高级体验
- **5 种双语排版样式**：柔色双语、左侧主题色引用竖线、虚线下划线、模糊点击揭晓（学外语利器）、纯译文替换。
- **输入框三连空格反译**：在网页任意输入框或评论区打完中文，快速连按 **3 次空格**，原地自动替换为目标语言（默认英文）。
- **划词即译与朗读**：选中任意外语片段弹出迷你「译」胶囊，点击即看译文并支持一键复制与 TTS 朗读。
- **按站点记忆**：支持为指定域名设置「始终自动翻译」或「永不翻译」。

## 二、自定义首页 / 新标签页与外观定制

打开 **「⋯ → 主页与定制」**（或 **「外观主题」**）：

- **自定义首页与新标签页**：支持独立配置或同步使用——可选 Aiko 原生极速起始页，或一键切换 **iTab（`https://go.itab.link/`）**、**WeTab**、**MTab**、空白页，或填入任意自定义网址。
- **新标签页秒开预热**：开启自定义新标签页后，在均衡/狂暴模式下后台预热 1 个隐形标签实例，点击新建标签瞬间直出 iTab，告别白屏闪烁。
- **底栏与手势**：可选在底栏常驻「主页键」与「巴别塔键」、切换 **标准底栏 / 极简胶囊栏**；支持**底栏左右滑动切换标签**、**底栏上滑拉出标签列表**、屏幕边缘手势与 185Hz 滚动自动隐栏。
- **Material / Material You 动态主题工坊**：7 套精选暗夜预设（黑曜靛蓝、Android 12+ 壁纸取色、赛博翡翠、樱花粉霞、熔岩琥珀、极光紫罗兰、`#000000` 纯黑 OLED）+ 色相/饱和度/浸染滑块与 `#RRGGBB` 调色台，零重启全窗口即时换肤。
- **AMOLED 深夜护眼与字体**：支持按时间自动切换日夜模式、零触摸拦截的深夜亮度压暗（0–70%）与暖色温滤镜（0–60%）；支持导入手机本地 `.ttf / .otf` 字体、设定最小字号与全局强制双指缩放。

## 三、油猴脚本完全体 & 离线 WebDevTools

打开 **「⋯ → 油猴脚本」**：

- **Greasy Fork 真·一键安装**：点击「前往 Greasy Fork 发现脚本」，在任意脚本页点击绿色「安装此脚本」将直接跳过“请先安装扩展”提示，立即弹出 Aiko 主题安装卡片（完整展示版本、作者、匹配站点、自动换行 `@grant` / `@connect` 徽章、`@require`/`@resource` 数量与可展开源码）。
- **多种导入方式与原位更新**：支持 **本地 `.user.js`**（亦可在系统文件管理器中直接选择用 Aiko 打开）、**粘贴脚本**、**网址安装**；覆盖更新同名脚本时 100% 保留已有 `GM_setValue` 存储数据；顶部提供 **「检查全部脚本更新」** 一键拉取新版本。
- **完整 GM 接口**：支持隔离世界（`JavaScriptExecutionWorld`）及三层兼容模式，提供 `GM_xmlhttpRequest`（受 `@connect` 弹窗授权保护且跨源重定向自动剥离敏感头）、`@require` / `@resource` 安装时本地缓存、`GM_getResourceText/URL`、`GM_addValueChangeListener`（跨标签实时同步）、`GM_registerMenuCommand`（当前页生效脚本下直接展示可点击按钮）、`GM_download`、`GM_addStyle`、`GM_addElement`、`GM_setClipboard`、`GM_openInTab`、`GM_notification`、`unsafeWindow` 与 `window.onurlchange`。
- **内置离线调试台**：点击 **「⋯ → 网页调试台」**（或输入 `/devtools`）弹出零外链悬浮 `DEV` 面板，提供 Console + JS REPL、Network 抓包、Cookie/LocalStorage 管理与 Elements 点选检查。

## 四、性能引擎与 185Hz 硬件调度

点击起始页性能胶囊或 **「⋯ → 性能引擎」**：

- **狂暴性能（Rampage）**：锁定最高刷新率（最高 185Hz）+ Android 12+ 突发式 **ADPF 大核助推** + 最多 12 个活跃标签保活 + 5 页 BFCache + 激进预加载与预握手 + 单前台预光栅化 + 128 路下载并发上限。
- **智能均衡（Balanced，默认）**：最高刷新率 + 6 个活跃标签 + 3 页 BFCache + 智能预连 + 64 路并发。
- **持久省电（Eco）**：60Hz 省电 + 3 个活跃标签 + 1 页 BFCache + 16 路并发。
- **无限自定义模式**：自由组合全部 9 项硬件调度参数（含全局 185Hz 抗卡盾），底部可随时开启零后台开销实时帧率浮标（HUD）。

## 五、广告过滤、站点盾牌 X-Ray 与网页自由套件

### 广告过滤与规则中心（`⋯ → 广告过滤`）
- **7 套内置实时规则（152,033 条）**：AdGuard 中文、CJX 弹窗引流净化、AdGuard 移动广告、打开 App 横幅净化、EasyList、EasyPrivacy、AdGuard Cookie 隐私弹窗；支持单列表开关与一键在线更新。
- **在线订阅与小白规则**：内置 8 套中国 + 全球精选订阅（`anti-AD`、`AdRules`、`EasyList China`、`Peter Lowe`、`HaGeZi`、`AdGuard 烦人元素`、`uBlock Origin` 等）一键添加，支持自定义 ABP 订阅链接、一键屏蔽/放行域名、可视化 **点选屏蔽（Element Picker）** 与手写 ABP 规则。

### 站点盾牌 X-Ray（点击地址栏左侧盾牌）
按精确主机名实时展示首帧/完成耗时与拦截详情，独立控制：
- **基础控制**：广告过滤、185Hz 抗卡盾、站点强制高刷、站点 JS、网页暗黑三态、桌面标识、网络图片、站点字号（75%–200%）。
- **v0.4.0 网页自由进阶**：**解除禁止复制/选中/右键**、**强制双指缩放**、**定时自动刷新（15s / 30s / 60s / 5m）**、**站点自定义 CSS**、**一键重置此站 Cookie/存储**，以及 **本站点点选屏蔽规则列表（误屏蔽一键撤销）**。

## 六、效率快捷键、媒体套件与全量备份

- **地址栏 `!bang` 瞬搜与 `/命令`**：
  - 内置 20 组瞬搜（如 `!gh 关键词` 搜 GitHub、`!gf` 搜 Greasy Fork、`!b` 搜 B 站、`!yt` 搜 YouTube、`!ld` 搜 Linux.do、`!zh` 搜知乎等），并可在定制中心自由增删自定义 `!bang`。
  - 支持快捷指令：`/babel`、`/devtools`、`/gallery`、`/longshot`、`/qr`、`/backup`、`/unlock`、`/dark`、`/clean`、`/settings`。
- **超级长按菜单与小窗预览**：长按链接支持后台静默打开、**Arc 风格半屏 Peek 小窗预览**、无痕打开、主题二维码、以图搜图（Google Lens / Yandex / SauceNAO / Bing）、原图保存与快速翻译。
- **视频与下载增强**：全屏视频手势（左亮度 / 右音量 / 横滑进度 / 长按临时 `2.0x` 倍速）、后台播放与锁屏通知控制、页内 `.mp4/.m3u8/.mp3` 嗅探与 128 线程可视化下载面板；另有 **185Hz 沉浸看图相册**、**真·网页长截图**、**PWA 桌面独立全屏应用**、**剪贴板智能感知胶囊**、**防跳转 App 卫士**、**原生 TTS 网页朗读** 与 **表单草稿防丢失保护**。
- **一键全量备份恢复**：在 **「⋯ → 数据备份与恢复」**（或 `/backup`）将主题、性能模式、书签、首页快捷方式、广告订阅与自定义规则、油猴脚本及脚本存储数据（含 `userscript_values`）、巴别塔配置与自定义指令一键打包导出为单个 `.aiko` 文件，换机重装一键恢复。
