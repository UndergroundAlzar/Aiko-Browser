# Aiko Browser 0.5.1 使用指南

[中文首页](../README.md) · [English overview](README.en.md) · [构建与验证](BUILD.md) · [像素画廊](art/README.md)

<a name="home"></a>

## 首页、新标签页与稍后读

在「主页与定制」选择原生起始页。默认的「原生页仅显示搜索框」同时适用于使用原生页的首页和新标签页。点搜索框即可输入网址、搜索词或 `!gh` 等搜索指令。也可以给首页与新标签页分别指定网址，或让新标签页跟随首页。

阅读网页时，打开菜单中的「稍后读」，可只保存链接与阅读位置，也可生成 MHTML 离线快照。要从首页访问书架，关闭「原生页仅显示搜索框」以显示快捷访问和稍后读区域。长按有快照的条目，选择「打开离线快照 (MHTML)」。快照生成失败时，书架仍保留链接。

<a name="babel"></a>

## 巴别塔双语翻译

在网页上输入 `/babel` 或打开「巴别塔翻译」。可选内置翻译服务、自定义 OpenAI 兼容端点或 Gemini 端点。开启页面翻译后，接近视口的段落才送译。流式回复中的段落连续 240 ms 没有新改动，才会进入翻译队列。另一段仍在输出时，已稳定的段落可以先完成。迟到的旧回包会被丢弃。

可选柔色、引用竖线、虚线、点击揭晓和纯译文五种样式。若只想翻译一小段，可以选中文字并点「译」。为输入框启用反译后，在支持的文本输入框中连按三次空格即可替换为目标语言。所选翻译服务会收到送译的文字。

<a name="filtering"></a>

## 广告过滤与站点例外

「广告过滤」管理内置列表、订阅和自定义规则。点地址栏盾牌可查看当前页面的拦截记录、开关本站过滤或调整站点设置。

WebView 支持 Service Worker 拦截时，浏览器从请求的 `Referer` 或 `Origin` 识别来源站点，再应用本站开关、第三方与资源类型规则及例外。缺少可用来源时放行。若请求只带来源域名，而该站有可能匹配的页面路径例外，浏览器也会放行，以免误拦被豁免页面的资源。

<a name="downloads"></a>

## 下载与完成记录

新增文件会排在当前文件后面，前一个完成后再开始下一个。可在任务面板暂停、继续或取消当前下载，并在「下载列表」移除等待项。队列会保存到本地，列表保留最近 30 条完成记录。

单个任务可配置最多 **128 路**分片。实际并行数受性能模式、文件大小和服务器对 HTTP Range 的支持影响。服务器只支持连续传输时使用单路。下载面板显示总进度、分片位置和各路状态。

<a name="performance"></a>

## 刷新率、性能提示与预连接

在「性能引擎」选择均衡、狂暴、省电或自定义配置。刷新率由显示屏、系统策略和当前模式共同决定。Android 12+ 设备及性能模式支持 ADPF 时，应用在触摸或导航后短时采集 UI 线程处理输入、动画、布局和绘制的实际帧耗时，按系统建议的间隔上报。交互窗口到期、进入全屏视频或界面停止时关闭采样。

开启预加载时，浏览器可向 WebView 提交 HTTPS 预连接提示。相同来源在 10 秒内去重，预连接能否执行取决于 WebView 的接口支持。省电模式关闭这类预连接。

<a name="backup"></a>

## 备份、换机与离线快照

打开「备份与恢复」或输入 `/backup`，选择导出方式。两种方式都可包含书签、历史、阅读偏好、书架、站点设置、脚本及其存储、过滤设置、自定义规则和字体。

| 导出方式 | Babel 凭据与恢复行为 |
| --- | --- |
| 便携备份（普通 `.aiko`） | 明文 ZIP，移除所有 Babel 配置的 API 密钥和自定义请求头。恢复时仅保留目标设备中配置 ID、API 格式和端点均匹配的本地凭据。书签、历史和脚本数据仍可被持有文件的人读取。 |
| 加密备份 | 选择「导出加密备份（含 API 密钥）」，并设置至少 8 个字符的密码。使用 PBKDF2-HMAC-SHA256 派生密钥，以 AES-256-GCM 加密并验证内容，可迁移 Babel 的密钥和自定义请求头。恢复需要相同密码。 |

恢复支持旧版 **v1** 便携备份。旧明文包即使含有 Babel 密钥，导入时也按便携备份处理。书架中的 MHTML 只收录索引引用、文件存在且在限额内的快照。恢复后路径会指向新设备，缺少快照的条目仍能打开原链接。备份上限为每项 20 MiB、解压后共 64 MiB、最多 128 项。WebView Cookie、缓存、下载队列和已下载文件不在迁移范围内。

<a name="tools"></a>

## 油猴脚本与网页工具

在「油猴脚本」中安装本地 `.user.js` 或从网址导入，查看脚本的匹配站点、权限与 `@connect` 域名。打开 `/devtools` 可查看 Console、页面发起的 fetch/XHR、DOM 和站点存储。其他常用入口包括「阅读模式」「网页朗读」「网页长截图」和「外观主题」。
