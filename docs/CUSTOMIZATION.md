# 站点控制、高刷策略、过滤与自定义指南

## 站点控制与极速 X-Ray

打开网页后点击地址栏左侧的盾牌，可进入「站点盾牌与极速 X-Ray」面板。顶部卡片实时显示当前页面的协议、首帧与加载完成耗时、BFCache 命中状态以及当前文档的拦截总数。

以下单站配置均按**精确主机名**保存，并分为兼容旧版的基础配置（`site_profiles`）与 v0.2.0 扩展配置（`site_extras`）：

- **广告过滤**：暂停或恢复当前站点的请求过滤与元素隐藏，切换后保留滚动位置刷新页面。
- **185Hz 抗卡盾（Ultra-Scroll）**：针对高刷长列表与信息流页面，通过纯 CSS 注入关闭高开销的 `backdrop-filter` 和卡片 `box-shadow`，并为常见文章/信息流容器启用 `content-visibility: auto`，减少滚动合成掉帧。即时生效，无需刷新。
- **站点强制高刷**：为当前站点锁定屏幕最高刷新率（覆盖全局刷新率策略）；全屏播放视频时仍会自动让步匹配片源帧率。
- **站点脚本 JS**：按站禁用或恢复 JavaScript，切换后保留滚动位置刷新页面。
- **网页暗黑**：三态切换（跟随全局 / 强制暗黑 / 强制浅色），配合「⋯ → 全局网页暗黑」使用系统 WebView 算法深色化能力。
- **桌面标识、网络图片与站点字号**：切换桌面模式会使用与系统 WebView Chromium 主版本一致的桌面 UA 并刷新当前页（表单提交或重定向后可按需手动刷新）；网络图片开关与站点字号（75%–200%）立即应用到当前 WebView。
- **拦截详情与恢复默认**：「拦截详情」保留当前文档内存中最近 12 条命中的请求域名、规则来源与规则文本（不写入磁盘，CSS 元素隐藏不计入请求数）。「恢复默认」会同时还原该站点的 `site_profiles`、`site_extras` 与过滤开关，保留普通标签的登录数据和历史。

## 过滤规则、单列表开关与点选屏蔽

### 内置列表独立开关

Aiko Browser 内置 EasyList、EasyPrivacy 与 AdGuard 中文列表。在地址栏盾牌的「过滤规则列表」区域，可以分别点击启停任意一组列表。规则引擎会优先读取对应组合指纹的二进制缓存（`filter-rules-v1.bin`），未命中时在后台编译并异步更新缓存。

### 点选屏蔽（Element Picker）

在站点盾牌点击「点选屏蔽」即可在当前网页进入可视化选区模式：

1. 直接点按页面上的广告位、横幅或悬浮栏，高亮框会标出选中区域并显示生成的 CSS 选择器及当前页面匹配数量。
2. 使用底部悬浮条的「扩大选区」向父节点逐层扩展，用「预览隐藏 / 恢复显示」即时验证效果。
3. 点击「保存屏蔽」后，选择器会经过安全校验（拒绝通配根元素与不安全字符），自动生成 `主机名##选择器` 规则并追加保存到自定义规则中，刷新或后续访问生效。

### 自定义过滤规则

打开「⋯ → 过滤规则 → 自定义规则」，每行填一条 ABP 规则（通过点选屏蔽保存的规则也会出现在此处，可随时编辑或删除）。保存时会逐行检查，遇到不识别的语法会标出行号。规则在后台编译，刷新网页即可应用。清空并保存可移除全部自定义规则。

```text
! 拦截广告域
||ads.example.com^
! 只在 forum.example.com 放行特定脚本
@@||metrics.example.com/widget.js$script,domain=forum.example.com
! 隐藏当前站点的赞助栏
forum.example.com##.sponsored-banner
```

自定义规则与已启用的内置列表合并，支持 `@@` 例外、`$document`、`$badfilter`、按站点的元素隐藏 `##` 与例外 `#@#`。上限为 2,000 条和 128,000 字符。支持 WebView 可见的常见 ABP 语法，脚本片段、URL 重定向和扩展过滤语法仍有缺口。

## 185Hz 刷新率策略与实时帧率浮标 (HUD)

打开「⋯ → 刷新率策略」（或在「⋯ → 性能记录」中点击「刷新率 / HUD」）可调整全局刷新率引擎：

- **极速高刷**（默认）：在保持当前物理分辨率与 HDR 能力的前提下请求屏幕最高刷新率模式（120–185Hz），在 Android 15+ 关闭帧率省电平衡并开启触控提频。
- **自适应**：将刷新率调度交由系统 LTPO / ARR 自动管理。
- **省电 60Hz**：选择不低于 60Hz 的最低刷新率模式以延长续航。
- **全屏视频自动让步**：进入全屏视频播放时自动暂时交还系统自适应，避免高刷与视频片源帧率冲突，退出全屏后自动恢复。
- **实时帧率浮标 (HUD)**：可选开关。开启后在后台线程采样 `Window.OnFrameMetricsAvailableListener`，悬浮显示当前屏幕 Hz、渲染 FPS、P99 帧耗与掉帧率；关闭时完全注销监听并退出后台线程，无后台开销。若在「极速高刷」下检测到系统限制了应用刷新率，面板会给出提示并提供跳转系统显示设置的入口。

## 搜索、首页快捷访问、稍后读、书签与手势

- **搜索引擎**：在「⋯ → 搜索引擎」或新标签页搜索框旁的引擎徽章处切换，内置 Google、Bing、百度、DuckDuckGo、Startpage、Kagi、GitHub，并支持自定义含 `%s` 占位符的 HTTP(S) 搜索模板。
- **首页快捷访问（Speed Dial）**：新标签页展示已固定站点（最多 16 个，首次使用预置 8 个常用站点）。在网页中通过「⋯ → 固定首页」或在书签列表中长按条目即可固定或取消固定。
- **稍后读（Reading Shelf）**：通过「⋯ → 稍后读 · 0MB」保存当前网页链接与滚动阅读位置，并可选择同时生成本地 MHTML 离线快照（保存在应用私有目录）。稍后读不常驻后台 WebView、不占标签内存，最多保存 120 条，在首页即可一键续读。
- **书签与历史（含 HTML 导入/导出）**：「⋯ → 书签 / 历史」均内置实时关键词筛选框（最多保存 500 条书签、160 条历史，完全兼容 v0.1.9 本地数据）。书签面板底部支持标准 Netscape Bookmark HTML 格式的「导入 HTML」与「导出 HTML」（默认文件名 `aiko-bookmarks.html`）。
- **手势、隐栏与阅读辅助**：「⋯ → 手势与隐栏」可独立开关「滚动自动隐藏底栏」与「屏幕边缘手势前进/后退」（开启时动态更新系统手势避让区，关闭时立即清除避让区）。底部地址栏支持左右滑动快速切标签、上滑打开标签列表；「⋯」面板同时提供沉浸式**阅读模式**、单标签**静音**、**页内查找**与**打印/PDF**。

## 油猴脚本

从「⋯ → 油猴脚本 → 导入脚本」粘贴源码、打开本地 UTF-8 `.user.js` 文件，或输入 HTTPS 的脚本源码地址。导入时会显示命名空间、匹配和排除网址、运行时机以及 GM 授权。导入或替换后默认关闭，进入脚本详情启用，刷新网页即可运行。在详情的「管理」菜单也可编辑或删除脚本。

- 匹配支持 HTTP(S) 的 `@match`、通配符 `@include`、`@exclude` 和 `@exclude-match`。仅在普通标签的顶层文档执行，v0.2.0 在注入前增加协议与主机名快速守卫以降低非匹配页面与子帧的开销。时间支持 `document-start`、`document-body`、`document-end` 和 `document-idle`。
- 支持 `GM_info`、`GM_log`、`GM_addStyle`、`GM_getValue`、`GM_setValue`、`GM_deleteValue`、`GM_listValues` 及对应的 `GM.*` 形式。每个脚本可保存最多 128 个键、合计 32,768 字符。
- **存储拆分与旧版迁移兼容**：v0.2.0 将脚本键值持久化拆分至独立的 `userscript_values` 存储，避免频繁写入影响脚本列表；读取时若新存储尚无对应键，会自动回退读取旧版（v0.1.9）保存在 `userscripts` 中的 `values-<id>` 数据，覆盖升级后已保存的脚本与键值无需重新迁移。同一文档内立即可见自己的修改，跨标签的新文档快照采用空闲分帧增量刷新，减少高刷滚动干扰。
- 新版系统 WebView 支持独立的脚本环境。无授权脚本可用 `@sandbox raw` 选择与网页共享 JavaScript 环境，这时站点的脚本策略可能影响运行。老 WebView 可运行部分无授权脚本，隔离和早期注入请以脚本详情的提示为准。
- 依赖 `GM_xmlhttpRequest`、`GM_cookie`、远程 `@require` 或 `@resource` 的脚本暂不能安装。导入时会指出不支持的声明。

可以用下面的脚本快速验证。导入并启用后打开 example.com，标题会变成玫红色。

```javascript
// ==UserScript==
// @name         Aiko 样式测试
// @match        https://example.com/*
// @grant        GM_addStyle
// @run-at       document-end
// ==/UserScript==
GM_addStyle('h1 { color: #e84f79; }');
```
