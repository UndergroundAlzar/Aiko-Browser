# Aiko Browser

**[下载 Android 安装包 · v0.1.7](https://github.com/UndergroundAlzar/Aiko-Browser/releases/download/v0.1.7/Aiko-Browser-0.1.7.apk)**　·　[发行说明与校验](https://github.com/UndergroundAlzar/Aiko-Browser/releases/tag/v0.1.7)　·　[English](docs/README.en.md)

Aiko 是一个使用系统 WebView 的轻量 Android 浏览器。打开首页，只有一个能输入网址的搜索框。读长帖时可以把感兴趣的链接先放进后台标签，切过去时再加载。遇到大文件，打开下载面板，就能看到文件的哪一段已经写入、哪一路正在传输。

**Android 10 及以上** · **1.70 MB** · 普通 APK 安装，无需 Root。

## 从拇指够得到的地方开始

| 想做什么 | 怎么操作 |
| --- | --- |
| 编辑完整网址 | 点底栏中的域名。也可以直接在首页搜索框粘贴网址 |
| 把帖子里的链接留到稍后 | 长按普通链接，选「在后台标签打开」 |
| 新建或找回标签 | 长按标签按钮新建。点一下打开标签面板，再选「最近关闭」 |
| 临时放行一个站点 | 点地址栏左侧的盾牌，再点「暂停过滤」。可在同一处恢复 |
| 找到一段文字或收藏当前页 | 在「⋯」的「当前页面」一栏选择「页内查找」或「收藏」 |
| 查看下载进度 | 长按「⋯」直接打开下载面板；点分段地图可以跳到对应的字节范围 |

普通标签支持前进、后退和阅读位置恢复。最近最多五个网页保留在内存中；重新打开应用后，标签网址和顺序可恢复，动态时间线的阅读位置取决于页面能否重新加载到那里。

## 看见每一路下载

下载时，分段地图会随进度点亮。默认根据文件大小使用 **1–8 路**，新建任务时可指定 **1–128 路**的上限。面板分别显示总进度、实际活动路数、速率和预计剩余时间。展开任意一段，还能看到它在文件中的位置。

- **边读边下。** 默认「浏览优先」。打开新网页时，下载会短暂让路，也可以在下载面板切换到「下载全速」。
- **断线后接着传。** 对支持 HTTP 字节范围且返回强 ETag 的文件，Aiko 会校验版本，定期记录各段进度。单路临时失败，最多自动重试两次。服务器不满足分段条件时，使用单连接下载。
- **找回下载。** 应用进程被回收后，可在下载面板继续当前任务。文件完成后保存在系统的 `Download/Aiko Browser/`。当前版本一次管理一个任务。

## 过滤与无痕

首次安装就带有 EasyList、EasyPrivacy 和 AdGuard 中文规则快照。点「⋯ → 过滤规则」可查看实际启用的请求规则、站点元素规则和跳过的条目，也可手动更新。部分高级规则超出 WebView 过滤器支持的范围，YouTube 视频内广告仍需单独验证。[规则来源与许可证](app/src/main/assets/filters/NOTICE.txt)

无痕窗口使用单独的 Android 进程和 WebView 数据目录。关闭时会请求清理，下次打开前还会清理上一次的隔离目录。普通标签的书签、历史和登录数据与这个窗口分开。

## 性能与验证

在「⋯ → 性能记录」可查看系统 WebView 版本、当前屏幕刷新率，以及最近网页从导航开始到可以绘制的耗时。这个数字包含网络等待，适合在同一设备、同一页面上对照。

电脑端下载测试曾观察到 **128 路同时传输**，并逐字节核对了合并后的 128 MiB 文件。测试还覆盖了单路断开、限流、文件版本变化和下载进程被强制结束后的恢复。早期构建在一加 Ace 7 Pro 上有一次 **Speedometer 3.1 得分 46.0 ± 1.0** 的用户实测。v0.1.7 尚缺同条件复测。[构建、签名与复测指南](docs/BUILD.md)
